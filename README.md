# 🚀 Sobre o projeto

Este sistema web faz parte de um ecossistema completo de gerenciamento para hamburgueria, desenvolvido inicialmente durante meus estudos no **SENAI** e posteriormente evoluído com novas funcionalidades, melhorias estruturais e regras de negócio mais robustas.

A aplicação web é responsável por toda a parte administrativa e operacional do negócio, centralizando:

- Controle de estoque
- Gestão de produtos
- Controle de vendas
- Pedidos
- Indicadores
- Dashboard administrativo
- Gestão operacional em tempo real

---

#  Objetivo do sistema

O objetivo da aplicação é permitir o gerenciamento completo da hamburgueria através de uma interface administrativa centralizada, integrada com:

- 📱 Aplicativo do cliente
- 🍽️ Aplicativo do garçom
- 💻 Sistema administrativo web


# 🔧 Funcionalidades

# 📌 CRUD completo

O sistema possui gerenciamento completo de:

- Categorias
- Lanches
- Bebidas
- Insumos
- Pessoas
- Vendas
- Pedidos
- Entradas de estoque
- Relação Lanche × Insumo

---

# Controle de estoque inteligente

Sistema completo de movimentação de estoque:

- Registro de entradas
- Controle de quantidade
- Controle de valores
- Associação com notas fiscais
- Atualização automática do estoque

---

#  Relação Lanche × Insumo

Cada lanche possui vínculo direto com seus ingredientes.

Isso permite:

- Controle automático de estoque
- Baixa automática após vendas
- Controle de receitas
- Melhor gestão operacional
- Cálculo indireto de consumo

---

#  Personalização integrada aos pedidos

As alterações realizadas pelo cliente no aplicativo impactam diretamente o sistema administrativo:

- Remoção de ingredientes
- Adição de ingredientes
- Alteração de quantidades

Tudo isso ajusta automaticamente o consumo dos insumos.

---

# Controle automático de disponibilidade

Produtos podem ficar indisponíveis:

- Manualmente pelo administrador
- Automaticamente por falta de estoque

---

#  Gerenciamento de pedidos em tempo real

Fluxo operacional completo:

- ⏳ Aguardando
- 🔥 Em preparo
- ✅ Finalizado

---

#  Dashboard administrativo

Painel com indicadores importantes para tomada de decisão:

- Gráficos de vendas
- Fluxo operacional
- Controle de pedidos
- Indicadores administrativos
- Dados de desempenho

---

#  Integração entre sistemas

A aplicação centraliza informações de:

- Delivery
- Atendimento presencial
- Retirada/Balcão
